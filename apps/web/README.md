# SADEEMAN web workspace

Executable Next.js/React/TypeScript application. `pnpm dev:web` serves the local workspace; Fastify runs separately with `pnpm dev:api`. Build the monorepo first. `API_ORIGIN` is a server-only loopback proxy target, not a browser credential.

Real API-backed guest/history/chat/CRM/consent/voice flows, actual tool-result cards, Celestial Dunes Three.js lantern, themes and responsive layouts are implemented. Voice/full-duplex and provider availability are reported truthfully. Static legacy brand preview is reference material, not customer data.

See `../../CLAUDE_HANDOFF/START_HERE.md` and `QA_RESULTS.md` for setup, screenshots and acceptance limits.
